This section describes tasks specific to authentication and authorization, including how to enumerate users and groups.

Note that all commands include NTLM and Kerberos authentication.  You don't need to request a Kerberos ticket before executing a command to use Kerberos; the command is capable of requesting a Kerberos ticket when it runs.  For details on the various supported authentication scenarios, refer to the [Authentication Guide](../../syntax-auth.md).
